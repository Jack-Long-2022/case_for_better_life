# 0001 - 转述案例采用证据分级发布制，而非强制亲身实践制

多数转述案例的场景（如重病、失业、诉讼）本人无法亲身遇到，若要求"实践过才能发布"，知识库的覆盖面会塌缩为个人生活半径。决定：发布门槛从"必须实践"改为"两门任过其一"（已实践 或 已核实引用），且每篇发布物强制标注三级证据标签（[亲历验证] / [他人案例·已核实] / [他人案例·仅引用]），引用最低标准为渠道+日期+可识别来源，低于此标准不发布。真实性承诺由"我全都试过"改为"我永远告知证据等级"。[仅引用] 案例日后亲身实践后升级为 [亲历验证] 重发，作为实践论"再实践→再升华"的落地形态。

## Considered Options

- 强制实践制：覆盖面不可接受，大量高价值案例被拒之门外。
- 无标签自由发布：与洗稿搬运无异，摧毁"真实性"这一核心信任资产。
