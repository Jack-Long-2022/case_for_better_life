# 周日例会流程

每周日晚执行。两个工作流命令 + 两个人工卡点。每周只出 1 篇成稿，不日更。

## 阶段一：选题会

1. 运行 workflow `weekly-review`
2. 采编：清 `inbox/` → 生成/更新案例卡（`cases/`）→ 盘点存量 → 产出选题候选（每条附使命三问答案）
3. 产出《本周选题候选》清单
4. 盘点**待实践洞察**：insights/ 中提炼出但老总尚未在自己工作里实践的原则，挑一件本周的事带上（转述案例闭环的心跳）
5. **老总卡点 ①：拍板选题**——在会话中回复选哪条；三问含糊的就回 inbox 养着，本周也可以不选

## 阶段二：生产

5. 运行 workflow `produce-article`，参数 `casePath` = 选中的案例卡路径
6. 提炼师：案例卡 → `insights/` 可复用原则（更新已有优于新建）
7. 写手：案例卡 + 洞察 → `articles/` 母本六段成稿 + 3 个标题候选，并回填案例卡状态
8. **老总卡点 ②：终稿过目 + 一秒选标题**

## 阶段三：发布（当前手动）

9. 母本 md → doocs/md 渲染 → 粘贴知识星球（首发）+ 公众号
10. 发布后：案例卡状态改「已发布」，发布记录写进母本 frontmatter；评论与星球问答收进 `feedback/`

## 纪律

- 任何一步违背使命三问 → 停，回使命
- inbox 之外不得散落素材；散落 = 素材蒸发
- 平时想到什么，随时手动召唤采编处理素材，不必等周日
